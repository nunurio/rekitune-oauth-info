レキチューンのチャンネル運営を支える個人用ツール

Rekitune YouTube Reply Assistant

YouTubeチャンネル「レキチューン」の運営者が、自分のチャンネルに届いたコメントを確認し、返信を準備するためのアプリです。一般向けの利用登録は受け付けていません。

できること

  • 自分のチャンネルの動画・コメント・返信を取得して一覧表示する。
  • 対応状況を整理し、外部AIサービスを利用して返信候補を作る。
  • 運営者が内容を確認し、承認した返信をYouTubeへ送信する。

Googleとの接続

GoogleのOAuth認証とYouTube API Servicesを利用します。コメントの取得と返信に必要な権限として youtube.force-ssl を使用します。Googleアカウントのパスワードを本アプリが受け取ることはありません。

この公開ページはアプリの説明用です。アプリ本体、コメントデータ、認証情報は掲載していません。
