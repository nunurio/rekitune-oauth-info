Rekitune YouTube Reply Assistant

プライバシーポリシー

公開予定日：2026年10月11日

本アプリは、YouTubeチャンネル「レキチューン」の運営者が自分のチャンネルを管理するための個人用ツールです。Google OAuthとYouTube API Servicesを使用します。

取得する情報と利用目的

認証したチャンネルのID・名称、動画のID・タイトル等、コメントと返信の本文、投稿者の公開表示名・チャンネルID、投稿日時、公開状態等を取得します。コメントの表示、対応状況の管理、返信候補の作成、運営者が承認した返信の送信に利用します。OAuthのアクセストークンと更新用トークンは、Googleとの認証・接続維持に利用します。

保存と保護

取得データ、下書き、対応履歴は運営者が管理するコンピューターに保存します。認証情報はmacOSキーチェーンまたは暗号化した保存領域で保護します。本アプリがGoogleアカウントのパスワードを保存することはありません。

外部サービスの利用

コメントの分類や返信候補の作成では、運営者が利用する外部AIサービスに、コメント本文と必要な文脈を送信する場合があります。認証情報はこれらのAIサービスへ渡しません。生成した返信候補は運営者が確認してから使用します。外部サービスでの処理には、それぞれのサービスの規約とプライバシーポリシーが適用されます。

取得データを販売したり、広告配信のために提供したりすることはありません。Google APIから取得した情報の利用・転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

接続の解除とデータの削除

Googleアカウントの接続管理画面から、本アプリへのアクセスをいつでも取り消せます。取り消すと、以後のAPIアクセスに新たな認証が必要になります。取得済みデータの削除は下記窓口へ連絡してください。削除依頼または認可取消しの確認後、対象の認証情報と取得データを7日以内に削除します。YouTube上のコメントや公開済みの返信を、本アプリ内のデータ削除と同時に削除することはありません。

この公開サイトについて

この説明サイトにはアプリのログイン機能、アクセス解析スクリプト、広告を設置していません。サイト配信にはGitHub Pagesを使用し、配信元によるアクセス情報の取扱いにはGitHubのプライバシーに関する声明が適用されます。
